# Mini Python Toolkit

This project is an interactive command-line toolkit built in Python featuring a continuous menu loop and three practical mini-tools: a Number Guessing Game, a To-Do List Manager, and a Score & Grade Checker. Users can run any tool multiple times, handle invalid menu choices safely, and exit cleanly when finished.

## How to Run

1. Make sure Python 3 is installed on your machine.
2. Open a terminal in the project folder (`plp-python-week8`).
3. Run the program with:

```bash
python toolkit.py
